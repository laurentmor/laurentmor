## 👋 About me

I build CLI tools, scaffolding generators, and automation for enterprise data
and dev workflows — XML/SQL extraction pipelines, project generators with
CI/CD baked in, and the occasional itch-scratching script. Lately that means
a lot of Python packaging and TypeScript tooling; historically it's meant
whatever the job or the course needed (Java, C++, Go, C#, PowerShell — see
"Repo landscape" below for the full sprawl).

I care about test coverage, clean packaging, and not making the next person
(often future me) guess how something works. Software engineering
fundamentals — data structures, software construction & maintenance, agile
methods — are baked into how I approach things, not just something I did in
school. *(If you went through the same UQAM-style INF courses judging by my
repo names, hi.)*

He/him · Geek · Part-time rights advocate · Strong opinions on mandatory meetings.

📍 Montréal, QC · 🏢 [CGI](https://www.cgi.com) · 🐦 [@laurentmor](https://twitter.com/laurentmor)

## 🔧 Currently building

- **[create-fastify-enterprise](https://github.com/laurentmor/create-fastify-enterprise)** —
  a scaffolding CLI for enterprise-grade Fastify + TypeBox + MongoDB/Mongoose
  services: CI/CD, OpenAPI, Vault-ready config, and SPDX/REUSE license
  compliance out of the box. The "I was tired of setting this up by hand"
  project.
- **[CGI-tools](https://github.com/laurentmor/CGI-tools)** — a monorepo of
  Python dev utilities for SQL/XML transformation pipelines, with automated
  releases (Release Please), multi-version CI (Python 3.10–3.12), Codecov
  coverage tracking, and REUSE/SPDX compliance.

## 🔭 Currently exploring

- **Entity auditing in Spring Boot** — a small Hibernate Envers demo:
  `@Audited` CRUD entity, a custom `RevisionListener` that stamps *who*
  changed *what* onto every revision (tied into Spring Security login), an
  Actuator dashboard, and Swagger docs. Digging into how much "who did this
  and when" you get essentially for free once Envers is wired in correctly.
